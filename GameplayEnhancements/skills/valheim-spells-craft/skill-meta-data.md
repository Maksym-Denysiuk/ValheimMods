Purpose:
Plans, builds, tests and documents new HomeCheat commands, spells and extensions for our own Valheim (GameplayEnhancements in the ValheimMods repository), always from the repository docs; plan mode writes spec cards and a session plan, implement mode takes one card to code, build, test, docs and delivery; "done" forces the docs update and then proposes a session that refreshes this skill.

Allowed use:
Reads HomeOS and the submodule references/ValheimCustomMods/ (docs/, GameplayEnhancements/src/ and docs/), or the unpacked package; a copy of the skill ships in GameplayEnhancements/skills/. Runs scripts/commands-check.js (Node, read-only: local git log/diff, the docs, spells.txt, and Steam libraryfolders.vdf to find the game folder; --game takes a folder path). Edits src/Features/<Feature>/, the docs, the command index and catalog in the submodule, and spells.txt in the game's BepInEx/config/homecheat/ folder (an implement session swaps only its own planned "(soon)" lines, found by grepping spells.txt for `real form (<its session>)`, for the real form in the comment above, same id, adding at most a safety parameter the built command requires such as &confirm=1; a refresh completes such a swap a session missed); never edits src/Core/ without Maksym's yes (a wave 0 core brief from a plan he approved counts, for the listed changes only). Unattended runs (set by the session brief) take recommended answers as ASSUMPTION lines instead of asking, never for hosting, other players, default changes, core edits outside an approved wave 0 brief, cheat paths or public-repo hygiene; no-game runs send nothing to the game and end at build, selftest and a test list (done-gate trigger built, status B). Runs bash src/build.sh (csc compiles C# into DLLs staged in the game folder), a scratch console build of feature-local Unity-free maths in the session scratchpad (never in the repository), node scripts/valheim/packages/build.js, java PlantUML (render only), node scripts/valheim/lib/il-reader.js (read-only). Sends one command at a time to the HomeCheat inbox through GameplayEnhancements/send-command.ps1, own game and hosted worlds only; reads BepInEx/LogOutput.log. Writes LocalOutputs/<ts>/ (draft spec cards, backlog plan, refresh brief; outside HomeOS the brief goes next to the unpacked package); approved spec cards live in the public repository as GameplayEnhancements/docs/Backlog/<name>.md. Git commit and push of its own paths in the submodule (public repository) and HomeOS, never force; commits with git commit --only <own paths> because parallel sessions share the submodule index; MANIFEST.md and other sessions' builds in payload/ are left unstaged for the refresh after the wave, which commits them from a fresh build.js. Proposes (does not start) a refresh session; the refresh is attended because its security record needs a yes. No other network use, no secrets, never localConfigs/ or people/. Commits use git commit --only; when git pull --rebase refuses over other sessions' unstaged files it fetches and pushes if the remote has not moved, else a merge pull when no incoming file is dirty, never a stash. spells.txt has one owner at a time: a session sends its spell line to the owner instead of editing beside it; when the owner session is gone (ended, archived, not answering), it edits only after Maksym's yes.
