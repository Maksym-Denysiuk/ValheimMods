# HomeCheat spell bar, spell file v4. One line per entry:  id | label | command | flags
#   id: dotted numbers of any depth (2, 2.1, 6.1.3). 1 is the Hotbar (the 10 bar cells), not configurable. A level holds any number
#     of entries: past the game's per-layer limit the radial continues as a spiral (like the emote wheel).
#   title (a group or a sub-section): "id | label", or "id | label | | sticky" (sticky on a title = every spell below it is sticky)
#   command: the form of an inbox file (op=...&k=v); chain commands with ;;   @dummy only shows a toast (a spell not built yet)
#   flags (space separated): sticky (the radial stays on its level after the cast)  pin=F1..F10|S1..S10 (S = Shift+key: S1..S9 = Shift+1..9, S10 = Shift+0)
#     shift=<form added when Shift is held while casting> or shift=@<id> (Shift casts that spell)  shiftlabel=<name of the Shift version, "_" = space>
#     (Shift+F on an F cell casts the Shift version; the bar shows its name under the cell; Shift+1..= cells have none)
#     ask=<key>:<Label=value,...> one radial level per ask flag, in order; the answer replaces {key} in the command; "_" in a
#     label shows as a space; dynamic answers: @players @crops @trees @prefabs (more than 40 answers are split A-Z into sub-levels).
#     Back (right click) goes to the previous question, closing the radial cancels.
# F5 is also the game console key: a pin on F5 opens the console as well.
# "(soon)" lines: the command arrives later; the line above each one is its real form, swapped in by the session that builds it.
